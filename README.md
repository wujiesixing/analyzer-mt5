# Trade Lens — MT5 交易分析

Vue 3 + TypeScript + Vite + ECharts + SheetJS 纯前端项目，参考 [Trade Buddy](https://bmtrading.de/en/trade-buddy/) 的交易分析布局。无需后端、数据库或 MT5 账户密码。文件在浏览器中读取，数据与账户参数保存在 localStorage。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地地址（默认 http://127.0.0.1:5173）。

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

`dist/` 可部署到静态托管服务。依赖打包在本地，不使用运行时 CDN。首次安装 SheetJS 需要访问其官方 CDN。

## 已实现功能

- 账户总览：交易数、胜率、净利润、盈利因子、余额最大回撤、夏普比率、平均盈利与亏损、单笔期望。
- 余额 / 回撤曲线、月度盈亏、盈亏分布、品种与星期收益。
- 日期、品种、策略多选、方向、星期与 Magic 联动筛选。
- 明细搜索、分页与 Excel 导出。
- 开仓备注前缀 / Magic Number 策略归类、本地保存。
- 完整报告账户快照、未平仓持仓、资金调整记录和成交账本核对。
- 每日净盈亏 Pearson 相关性热图。
- 回测 Excel 导入，按交易序号比较余额曲线与统计指标。
- 蒙特卡洛重采样、分位曲线、期末亏损概率与回撤分位。
- 账户参数、JSON 备份恢复、清除本地数据、打印 / 保存 PDF。

首次打开显示明确标记的演示数据。导入会替换当前数据，请先备份。

## 导入格式

支持 MT5 完整历史 Excel 报告（历史持仓、历史订单、成交、未平仓持仓、工作订单、账户与结果），以及策略测试报告 `ReportTester`（设置、结果、订单、成交）。支持 `.xlsx`、`.xls` 和 `.csv`，最大 30 MB。兼容中文「盈利」「趋势」「开价时间」「结余」以及英文表头；重复「时间」「价位」分别识别开仓和平仓字段。原报告时间不做时区换算。

策略测试报告没有历史持仓。导入时按品种和方向，把开仓成交与之后的平仓成交配成一笔持仓：交易数对齐报告「交易总计」，方向和备注取开仓成交（例如 `USTEC_H_FIXED`），不使用平仓行上的 `sl` / `tp` 备注。开仓手续费计入该笔净盈亏。同一持仓被多次部分平仓时合并为一笔。初始入金和货币读取报告中的「初始入金」「货币」；有成交结余时起始资金仍以账本为准。测试报告通常没有账号 ID，策略规则不会按账号归档。

历史持仓作为交易统计唯一数据源，避免与成交重复累计。通过「历史持仓号 = 开仓成交订单号」关联开仓备注，缺少成交备注时回退到同号订单备注。不用退出成交的 `[sl ...]` / `[tp ...]` 备注识别 EA。未提供 Magic 时保留为空，界面显示 —，可按开仓备注前缀分组（例如 `PE_`、`RB-`）。不会凭空推断 Magic 或自动合并不同 EA 名称。

成交账本用于恢复实际余额走势与资金调整；从首笔成交结余减去该成交净变动，推算报告期间起始余额（不是账户创建时首次入金）。未平仓浮盈、未平仓开仓费用、余额调整不加入已平仓交易指标。账户快照读取 MT5 原报告余额与净值；导入时自动填入报告账户号、币种和可推算的起始余额。

导入弹窗可以下载通用模板。必需列：时间或开仓时间 / 平仓时间、品种、类型（buy / sell 或买入 / 卖出）、盈利或利润。可选：订单、手数、手续费、库存费、费用、Magic、备注、开仓价与平仓价。

成交表里同时有开仓和平仓时，按上面的方式还原持仓，不再把退出成交单独当作一笔交易。只有退出成交、没有开仓成交时，仍统计 out / out by / in/out：记录数为退出成交数，方向为退出成交方向，可能缺失入场手续费，界面持续显示提示。只读取第一个可识别工作表，不自动跨工作表合并。只含未平仓的报告不作为历史交易导入。数值采用标准小数点，不自动解析欧洲式小数逗号。

已使用用户提供的 `ReportHistory-1436589.xlsx` 验证：562 笔历史持仓、9 笔未平仓、562 笔开仓策略备注关联、1 笔余额调整，账本核对差额为 0。报告原文件和私人交易数据未复制到项目，也未打包到前端。

## 统计口径

净盈亏 = 利润 + 手续费 + 库存费 + 费用（费用使用带符号数值）。回撤计算已平仓余额峰值与后续余额之差，不包含浮动净值回撤。持平交易计入总交易数。筛选后余额从设定的起始资金重新累计。账户总览在完整成交账本可用时显示实际余额曲线，包含开仓费用和资金调整；回撤 KPI 仍按已平仓交易计算。修改起始资金时实际余额曲线平移，报告快照保持原值。

页面胜率、盈利因子、单笔期望与平均盈亏按每笔扣费后的已平仓净盈亏计算；MT5 原报告汇总保留并单独展示，可能与页面口径不同。例如参考文件已平仓净收益 $746.18，未平仓开仓费用 −$1.02，MT5 报告总净盈利 $745.16；资金调整 +$14.37 不计交易收益。

夏普比率使用有交易日净盈亏 / 固定起始资金，均值除以样本标准差并乘 √252，无风险利率为 0；不等同于完整日历净值的标准投资组合夏普。没有亏损而有盈利时盈利因子为 ∞。

相关性以全部交易日期为共同日期集合，无交易的策略记为 0，零方差相关系数显示 0。蒙特卡洛采用固定盈亏、有放回抽样，每次最多 1,000 笔交易，不模拟复利、时间依赖、成本变化或滑点。曲线为每一步的横截面分位数。

数据仅保存于当前浏览器和源站。清除网站数据或切换地址会影响可见数据，可用 JSON 备份迁移。没有文件上传请求。localStorage 有容量限制，保存失败会显示提示。币种切换只修改显示，不进行汇率转换。

## 代码结构

```text
src/
├── App.vue                   # 组装布局、提供共享状态、切换页面
├── pages/                    # 9 个功能页面
├── components/
│   ├── layout/               # 侧栏、顶部栏、页标题、提示、页脚
│   ├── account/              # 账户信息、报告快照、未平仓、资金调整
│   ├── analysis/             # 筛选器、KPI、绩效图表
│   ├── ImportDialog.vue      # 文件选择、拖放、模板下载
│   └── Chart.vue             # ECharts 生命周期与尺寸管理
├── composables/
│   ├── useTradeWorkspace.ts  # 共享状态、账户操作、导入、备份与本地保存
│   ├── useTradeAnalytics.ts  # 策略解析、筛选、统计、明细分页
│   └── useChartOptions.ts    # 余额、收益、相关性、回测与模拟图表配置
├── types/trading.ts          # 交易、报告、策略规则及共享状态类型
├── config/                   # 导航文案与星期常量
└── lib/                      # Excel 解析、纯统计计算
```

根组件通过 `provideTradeWorkspace()` 创建并提供唯一的工作空间。页面与业务组件通过 `useTradeWorkspace()` 获取需要的响应式状态，切换页面不会重新创建账户数据。KPI 展示组件通过 props 接收指标；文件输入引用由导入弹窗与回测页各自管理。共享主题和布局样式位于 `style.css`。

测试包括纯统计、真实 XLSX 字节读取、多分区 MT5 报告解析、共享状态的筛选与保存恢复，以及全部页面 / 布局 / 导入弹窗的 Vue 渲染检查。渲染检查不启动监听端口，不代表真实浏览器视觉验收。

## TypeScript 与关键注释

源码、Vite 配置和测试均采用 TypeScript，所有 Vue 组件使用 `<script setup lang="ts">`。`tsconfig.json` 开启 `strict`，`npm run typecheck` 通过 vue-tsc 检查 TS 与 Vue 模板；`npm run build` 先执行类型检查再生成生产包。TypeScript 固定在兼容 vue-tsc 的 6.0.x 系列。

`types/trading.ts` 定义已平仓交易、成交账本、未平仓持仓、报告元数据、统计指标、模拟结果与工作空间类型。JSON 恢复通过 `lib/workspaceValidation.ts` 检查未知运行时数据，避免仅用类型断言跳过备份内容校验。

关键中文注释覆盖：重复表头与报告分区识别、按持仓号关联开仓备注、持仓与成交去重、期间起始余额反推、资金调整与费用区分、余额峰值回撤、夏普年化口径、相关性缺失日期处理、蒙特卡洛重采样与分位曲线、共享状态注入与图表资源释放。
